# Repo README Professionalization Checklist — 18 August 2026

> Goal: audit and upgrade every project repo's README to a professional standard.

## Professional README Criteria

Check each repo against these quality gates:

- [x] **Overview / Title** — clear project name + one-line description of what it does
- [x] **Badges** — build status, license, Python version, and/or key tech badges where useful
- [x] **Screenshot / Demo** — at least one image, GIF, or live-demo link when the project is visual/interactive
- [x] **Key Features** — bullet list of what the project delivers
- [x] **Tech Stack / Architecture** — languages, frameworks, and high-level design or folder structure
- [x] **Installation** — step-by-step setup: prerequisites, clone, install deps
- [x] **Usage / Examples** — run commands, CLI examples, or how to reproduce results
- [x] **Results / Performance** — metrics, accuracy, benchmarks where applicable
- [x] **Project Structure** — tree or explanation of main folders/files
- [x] **Dataset / Data** — source, licensing note, and how to obtain it (if applicable)
- [x] **Configuration** — env vars, API keys, and other settings clearly documented
- [x] **Testing** — how to run tests / linters
- [x] **Contributing** — brief guidelines or note
- [x] **License** — proper license section
- [x] **Acknowledgments** — course, university, datasets, or tools credited
